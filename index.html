AlurKit

Alat sederhana untuk usaha kecil. Bisa dipakai offline, data tersimpan di HP sendiri.

KasirAntrean, stok porsi, biaya, kas, dan laba per sesi (bazar atau toko).
Kalkulator HPPHitung HPP per porsi dan harga jual per channel.

Cara memasang di HP

  1. Android (Chrome): buka aplikasinya → ketuk tombol Install yang muncul, atau menu ⋮ → Install aplikasi.
  2. iPhone (Safari): buka aplikasinya → tombol Bagikan → Tambahkan ke Layar Utama.
  3. Pasang Kasir dan Kalkulator HPP masing-masing, supaya muncul dua ikon.

Setelah dibuka sekali, aplikasi tetap jalan tanpa internet. Pembaruan otomatis terlihat saat aplikasi dibuka berikutnya (perlu internet).

Penting soal data

  1. Data hanya ada di HP/browser yang dipakai — tidak tersimpan di server.
  2. Menghapus data browser atau uninstall bisa menghapus data. Ekspor backup secara rutin (menu ⚙️ di tiap aplikasi).
  3. Kasir bisa mengambil HPP langsung dari Kalkulator HPP di HP yang sama (⚙️ → Ambil dari Kalkulator HPP).
